ISTQB CTFL Quiz Simulator

A desktop practice-exam simulator for the ISTQB Certified Tester Foundation Level (CTFL v4.0) syllabus. It builds randomized, timed exams from a sourced question bank, lets you mark questions for review, and explains every answer when you submit.

  • Real in this demo12 questions copied unchanged from the repo's question_bank.json, with their explanations and source references, plus the app's 65% pass mark.
  • Scaled downThe app draws 40 questions from its 96-question bank with a 60-minute timer. This demo draws 8 of the 12 with a 12-minute timer (the same 90 seconds per question).
  • Not hereHistory saved to exam_history.json, JSON/CSV export, and the terminal mode in cli_quiz.py. Those need Python 3.12+ and the repository.

What the real app adds

Desktop app Real

  • 96 adapted questions from ISTQB CTFL v4.0 Sample Exams A, B, C and D.
  • 40-question randomized exams with a 60-minute countdown that submits automatically at zero.
  • Answer order reshuffled every attempt while keeping the correct answer intact.
  • Attempt history saved locally in exam_history.json, shown newest first, with delete, clear, and JSON/CSV export.
python ISTQBQuizApp.py

Terminal mode Real

  • The same exam and history logic in cli_quiz.py, with ANSI styling, a progress bar, and a question map.
  • Commands such as review, history, export-json, export-csv, restart, and help.
  • Not re-created on this page.
python cli_quiz.py

Both need Python 3.12 or later and a clone of the repository. Tkinter ships with most Python installers.

Question sources. Every question on this page is an adapted version of a question from the official ISTQB® CTFL v4.0 sample exams, as stored in the project's question_bank.json. The source line under each explanation names the exact sample exam and question. ISTQB® is a registered trademark of the International Software Testing Qualifications Board, which holds the copyright to the original sample exams. Get the originals from the ISTQB CTFL v4.0 certification page on istqb.org.

This is a study simulator for practice only. It is not an official ISTQB exam product, and a score here does not predict a certification result.
